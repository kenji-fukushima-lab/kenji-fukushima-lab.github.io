# Website audit follow-up — 2026-09-08

This pass extended the earlier audit to interactive failure states, keyboard
navigation, all generated content routes, structured data, dependency security,
and third-party script integrity.

## Fixes

- **Genome viewers:** an NCBI script download failure was cached permanently.
  The loader now removes the failed script and resets its promise so the
  re-enabled button actually retries. Both viewers still share one successful
  script download.
- **Code copying:** the button previously reported success before the clipboard
  promise settled, left rejections unhandled, and trimmed meaningful indentation
  and trailing newlines. It now preserves the code, reports success or failure
  through localized live status, and permits retry. Keyboard focus now makes
  the otherwise hidden copy control visible.
- **Quiz navigation:** focus now moves to the new choices after starting or
  advancing, and to the result heading after completion. Status changes are
  announced to assistive technology.
- **Incomplete quizzes:** a failed background photo request previously produced
  the same completion message as a full ten-question run. Results now identify
  the interruption and count the questions actually answered.
- **404 pages:** removed the three-second forced navigation that interrupted
  reading. Both languages retain their noindex directive and offer search and
  a home link without a time limit.
- **Research networks:** MDB's important outline-button colors overrode the
  intended accessible styling. Dedicated button styles now follow the site
  theme in normal, focused, and hovered states. Toolbar instructions also use
  the theme's readable secondary text color in dark mode.

The new browser regressions reproduced the original viewer, clipboard, keyboard,
and quiz defects. The expanded axe sweep reproduced the 404 refresh and network
contrast failures before their fixes. 404 and both network routes are now in the
regular accessibility suite, with network coverage in mobile and dark mode too.

## Additional checks

- Production build, Pagefind indexing, CSS optimization, and
  `npm run checks:push` passed (64 Python, 14 JavaScript, 17 Ruby tests).
- All 102 Chrome browser tests passed. Another 16 focused tests passed in
  Firefox, covering complete/interrupted quizzes, copying, NCBI loading,
  network controls, 404 navigation, search, and storage restrictions.
- A full axe sweep of 153 document routes completed without navigation errors.
  After the fixes, the only remaining violations were inside YouTube frames
  on three routes; none were in the site's own document content.
- All 155 generated HTML files had valid local links and anchors. The language
  alternatives had existing targets, and all 455 JSON-LD blocks parsed.
- Both Atom feeds and sitemap targets passed validation; all 1,871 responsive
  image width descriptors matched the actual images.
- `npm audit` reported zero known vulnerabilities in the installed dependency
  tree. This is an advisory-database check, not a complete security guarantee.
- Downloaded bytes matched the rendered SRI hashes for jQuery, Chart.js,
  medium-zoom, and D3.
- Lighthouse passed three samples each for the English/Japanese quiz and
  research-network pages (12 reports). Accessibility, best practices, and SEO
  scored 100 throughout; performance scored 90–93. These are validation scores,
  not a before/after optimization claim.

## External-service limits

The full axe scan also entered YouTube's embedded players and reported invalid
ARIA attributes and unnamed buttons on the two outreach pages and the Japanese
Taipei workshop post. Those controls are served by YouTube, outside this
repository's DOM and source. No accessibility rules were relaxed to conceal
these findings; the existing regular suite's YouTube-frame exclusions remain
unchanged.

NCBI and iNaturalist failure/success scenarios use controlled browser fixtures.
They verify this site's loading and recovery logic without assuming external
service availability or sending messages, access requests, or social posts.
